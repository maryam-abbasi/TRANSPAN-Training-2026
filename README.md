# TRANSPAN-Training-2026

Hands-on materials for the 2-day immersive training school focused on the fundamentals of Artificial Intelligence for analysis of -omics data in the context of biomarker discovery and translational medicine for pancreatic cancer.

## Event Details

* **Dates:** September 14-15, 2026

* **Host:** University of Coimbra, Portugal / 
            Univeristy Politecnic of Santarém / Online

* **Program:** COST Action CA21116

## Repository Contents

* **Day 1 Notebook:** Practical session 1: building and judging a diagnostic model.


* **Day 2 Notebook:** Practical session 2 materials.
* **Datasets:** Clinical data files containing features like urinary biomarkers, age, sex, and CA19-9 for predictive modeling.


* **Reference Documents:** Relevant papers (e.g., Debernardi et al. 2020) and supplementary materials.



## How to Use the Notebooks

All hands-on work is designed to run entirely in Google Colab, meaning there is nothing to install locally. **You do not need to know Python**; the sessions are built so you can read, run, and make small modifications to pre-written code.

1. Click the specific Google Colab link provided in our Microsoft Teams chat.
2. Sign in with your Google account.
3. Click inside the grey code cells and press **Shift + Enter** to execute them.


4. Ensure you run the cells in order, from top to bottom.
